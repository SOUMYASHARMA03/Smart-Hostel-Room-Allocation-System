# 🏨 Smart Hostel Room Allocation System

A desktop-based Smart Hostel Room Allocation System developed using **Java Swing** and **Data Structures & Algorithms (DSA)** to automate hostel room allocation, student management, waiting lists, and allocation history.

## ✨ Features

- 🔐 Secure Login System
- 👨‍🎓 Student Registration & Management
- 🏠 Smart Room Allocation
- 📋 Waiting List Management
- 🤝 Roommate Compatibility
- 📊 Reports & Allocation History
- 💾 File-Based Data Storage
- 🖥️ Interactive Java Swing GUI

## Highlights

- Java Swing Desktop Application
- Custom Linked List Implementation
- Priority Queue Based Room Allocation
- Hash Map for Fast Room Search
- Stack for Allocation History
- Object-Oriented Design


## 🧠 Data Structures Used

- Doubly Linked List (Student Records)
- Priority Queue (Room Allocation Priority)
- Hash Map (Fast Room Lookup)
- Stack (Allocation History / Undo Operations)

## 🛠️ Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- File Handling
- Collections Framework
- Custom DSA Implementations

## 🚀 How to Run

### Run the project

1. Clone the repository

```bash
git clone https://github.com/SOUMYASHARMA03/Smart-Hostel-Room-Allocation-System.git
```

2. Open the project in VS Code or IntelliJ IDEA.

3. Ensure Java JDK 17 (or your project's required version) is installed.

4. Run `Main.java` to start the application.
